# Domain Docs

ColorLUThier uses a single domain context.

## Before exploring

Read:

- `CONTEXT.md` at the repository root, when present.
- Relevant ADRs under `docs/adr/`, when present.

Missing domain files are not an error. The domain-modeling workflow creates them lazily as terminology and durable architectural decisions are resolved.

## Vocabulary

Use the canonical language defined in `CONTEXT.md` in issue titles, specifications, tests, and implementation discussions. Avoid synonyms that the glossary explicitly rejects.

## Architectural decisions

Surface any conflict with an existing ADR explicitly instead of silently overriding it.
